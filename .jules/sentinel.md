## 2025-05-15 - Hardcoded JWT and Unprotected Edge Functions
**Vulnerability:** Several sensitive Edge Functions (e.g., `ai-study-assistant`, `extract-document-text`) were configured with `verify_jwt = false` in `supabase/config.toml`. Additionally, frontend code in `src/pages/AIStudyAssistant.tsx` used a hardcoded anonymous JWT for authorization headers, and `src/integrations/supabase/client.ts` contained hardcoded Supabase credentials.
**Learning:** Default configurations or quick prototyping often leads to insecure defaults like `verify_jwt = false`. Hardcoding JWTs or credentials in frontend code is a critical security risk as they are easily accessible to anyone viewing the source.
**Prevention:** Always set `verify_jwt = true` for Edge Functions that handle sensitive data or perform authenticated actions. Use `supabase.auth.getSession()` to dynamically retrieve session tokens for frontend-to-Edge-Function communication. Store all configuration constants in environment variables and access them via `import.meta.env`.
