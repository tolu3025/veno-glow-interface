## 2025-05-22 - [Securing Edge Functions and Frontend Routes]
**Vulnerability:** Multiple AI-related Supabase Edge Functions were accessible without authentication (`verify_jwt = false`), allowing potential resource exhaustion and unauthorized AI usage costs. Additionally, sensitive frontend routes were accessible to unauthenticated users, and some components used hardcoded anonymous keys for function calls.
**Learning:** Defaulting to `verify_jwt = false` in development can easily leak into production. Manual `fetch` calls to Edge Functions often bypass the automatic auth handling of the Supabase client, leading to the use of hardcoded keys or unauthenticated requests.
**Prevention:** Always set `verify_jwt = true` for sensitive or costly Edge Functions. Use `supabase.functions.invoke()` where possible to benefit from automatic JWT inclusion. If manual `fetch` is required (e.g., for streaming), dynamically retrieve the session token using `supabase.auth.getSession()`. Ensure all sensitive frontend routes are wrapped in a `ProtectedRoute` component.
